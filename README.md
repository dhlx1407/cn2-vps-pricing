## 先分清：你说的 CN2，到底是哪一种 CN2

便宜 CN2 VPS 之间差价悬殊，根源在于「CN2」这三个字母后面藏着的线路等级完全不同。

CN2 是中国电信的下一代承载网（AS4809），GIA（Global Internet Access）是其中优先级最高的精品线路。普通 VPS 走的是老 163 骨干网（AS4134），晚高峰丢包率可以飙到 30% 以上；CN2 GT 属于 CN2 的二级线路，这几年也开始拥堵；只有 CN2 GIA 保持在晚高峰低丢包的水平。据第三方评测，CN2 GIA 的 IP 中转报价最高能到每兆 120 美元，这就是 GIA 线路 VPS 贵的物理原因。

搬瓦工的命名规则值得单独记一下：

- **CN2 套餐**：走 CN2 GT 线路，入门款年付 $49.99。比普通 163 强，但晚高峰表现不如 GIA。
- **CN2 GIA-E 套餐**：招牌产品。E 代表 ECOMMERCE（电商级），电信回程走 CN2 GIA、移动走 CMIN2、联通走优质线路（AS10099），带宽 2.5Gbps 起步、最高 10Gbps，并且支持十几个机房间自由切换。
- **香港 / 日本 / 新加坡 CN2 GIA**：单机房固定线路，延迟最低（香港 30–50ms），但价格最贵、流量配额小、不可迁移。

一句话：同样是「CN2 VPS」，$49.99/年 买到的是 GT 或普通线路，$169.99/年 才是三网 GIA。商家宣传页不写清这一点，是低价 CN2 套餐最常见的猫腻。

## 只写在面板和条款里的几个限制

这些信息散在 KiwiVM 面板和官方文档里，购买前值得知道：

1. **只支持 Linux**。Debian、Ubuntu、CentOS、AlmaLinux 都行，Windows 装不了。需要 Windows 远程桌面环境的，这个预算下看别家。
2. **流量按上传 + 下载双向计算**（第三方评测提到的口径），1TB 月流量实际可用的传输量要按双向理解。KiwiVM 后台可以设置 80% 流量预警，建议买完就开。
3. **超额处理方式说法不一**。有评测称超额后直接停机到下个计费周期、不自动扣费；也有整理页称可按 $1/GB 付费或升级套餐。下单后在面板里确认自己账户的策略，避免意外。
4. **被 DDoS 攻击只能黑洞 IP**。官方文档写明因 CN2 GIA 容量有限，遭遇攻击时只能 nullroute 处理。做高风险业务需要自己套 Cloudflare 或另购高防。
5. **机房迁移有边界**。GIA-E 套餐可在十几个机房间一键迁移、不丢数据、不重装系统；但香港 / 日本 / 新加坡套餐固定机房不可迁移；DC9 的 CN2 GIA 套餐也只能留在 DC9。
6. **香港套餐流量偏小**。入门款月流量只有 500GB，价格却是 GIA-E 的五倍以上，为低延迟付费时流量账要算清楚。

这几条里最容易被忽略的是第 1 条和第 2 条——不少人是冲着「便宜 VPS」来的，买完才发现装不了 Windows，或者发现 1TB 流量按双向算没想象中耐用。
